\subsection{Continuous flows to flow matching}

\begin{equation}
    \label{eqn:flow_ODE}
    \frac{d}{dt}\psi_{t,x}(\theta) = v_{t,x}(\psi_{t,x}(\theta)), \quad \psi_{0,x}(\theta) = \theta
\end{equation}

\begin{equation}
    \label{eqn:final_density}
q(\theta|x) = (\psi_{1,x})_* q_0(\theta) = q_0(\theta_0) \exp\left(-\int_0^1 \text{div}\, v_{t,x}(\theta_t) \, dt\right)    
\end{equation}

In~\cref{eqn:final_density} $v_{t,x}(\theta)$ can be approximated by a neural network. The issue is training the network is prohibitavely expensive.
Starting with a sample $\theta_1$ we need to integrate the ODE~\cref{eqn:flow_ODE} numerically which involves lots of neural network evaluations. We also need to calculate the divergence of
the network with $\theta_t$ which again must be numerically approximated. This is prohibitavely expensive. 

The major improvement in flow matching is allowing use to use continuous flows but with feasible trianing. In this we use a condition vector field which therefore means that training does not involve
integrating ODEs.
